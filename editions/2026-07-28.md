## Research & Papers

- **[DecoupleMix: principled VLM pretraining via decoupled ratio search and convex allocation](https://arxiv.org/abs/2607.24516)** — Proposes a method for constructing VLM pretraining mixtures that decouples ratio search from convex allocation, enabling attribution of model performance to specific data sources at scale. *(arXiv)*
- **[The physics of multi-turn long-horizon planning: from pre-training to post-training via agentic distillation](https://arxiv.org/abs/2607.24720)** — Systematic study of how long-horizon planning ability is acquired in foundation model agents, proposing single- and multi-teacher on-policy agentic distillation that significantly improves planning across the full training pipeline. *(arXiv)*
- **[LOCKS: page-local compact key summaries for efficient long-context decoding](https://arxiv.org/abs/2607.24555)** — Introduces page-local compact key summaries that replace full KV-cache reads during LLM decoding, achieving significant speedups for long-context inference while maintaining output quality. *(arXiv)*
- **[DraftExpert: expansion-aware self-speculative decoding for end-device MoE inference](https://arxiv.org/abs/2607.24434)** — Enables efficient MoE inference on consumer devices by staging routed experts on demand, dramatically reducing latency for single-user settings without sacrificing quality. *(arXiv)*
- **[SpecBox: speculative sandbox scheduling for efficient LLM agent serving with MCP](https://arxiv.org/abs/2607.23933)** — Introduces speculative sandbox scheduling for LLM agents using the Model Context Protocol, reducing memory overhead while maintaining low tail latency for sandboxed tool execution. *(arXiv)*
