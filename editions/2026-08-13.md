## Lead Sign language AI: Google DeepMind ships SL2T, bringing sign-to-text AI to Pixel 11

Google DeepMind unveiled SL2T, a multilingual sign-language-to-text model trained on over 100,000 hours across 50+ sign languages, powering sign-to-text dictation in Gboard and Live Transcribe on Pixel 11 starting with ASL-to-English. Pose tracking runs on-device for privacy, marking the first consumer deployment of sign language AI.

Source: [Google DeepMind](https://deepmind.google/blog/putting-sign-language-ai-into-users-hands/)

## Tools & Startups

- **[Ballet — workflow automation that writes integrations against any API](https://www.ballet.dev/)** — Describe a multi-system outcome in plain English and Ballet writes the integration against any API, producing reviewable, version-controlled code that is deterministic where accuracy matters and agentic where judgment helps. *(Ballet)*
- **[GreenTree — test the tree, not every commit](https://github.com/Reachpad/greentree)** — An open-source Rust tool that content-addresses your dirty working tree, caches test verdicts by tree hash, and refuses to publish any tree that hasn't passed checks. Built for coding agents with a drop-in Claude Code skill. *(GreenTree)*
- **[Agent Memory Leaderboard — first public benchmark for agent memory systems](https://agentmemoryleaderboard.ai/)** — A new open benchmark for comparing textual and coding-agent memory systems under a consistent Add/Search evaluation flow, with separate academic and commercial tracks; first-cycle results due mid-August. *(Agent Memory Leaderboard)*
- **[Decant — local-first analysis of Claude Code and Codex sessions](https://github.com/dosu-ai/decant)** — A local-first CLI/web tool that turns Claude Code and Codex session logs into token spend, context windows, files touched, and cost insights, with full-text search across transcripts and no outbound network calls at runtime. *(Decant)*
