## Lead Voice goes full-duplex: OpenAI ships GPT-Live full-duplex voice for ChatGPT, rebuilt in six months

OpenAI rolled out true full-duplex voice to ChatGPT Voice, letting the assistant listen and speak at the same time via a turnless speech model with a dedicated audio fast path and async reasoning. The overhaul cuts voice-session startup from six network round-trips to one, and the team detailed how they shipped it in just six months.

Source: [OpenAI](https://openai.com/index/continuous-voice-interaction-with-gpt-live/)

## Research & Papers

- **[WorldExam: a benchmark for world models from appearance to reactivity](https://arxiv.org/abs/2608.02603)** — A hierarchical diagnostic benchmark spanning visual quality, control adherence, spatial consistency and world reactivity across 1,474 cases and eight tasks, unifying evaluation of camera-, action- and language-driven world-model paradigms. *(HuggingFace)*
- **[Structured memory for edge LMs: O(1) SSM state injection kills KV-cache growth](https://arxiv.org/abs/2608.02560)** — State-space models can eliminate both Transformer KV-cache growth and RAG prefill cost by injecting corpus state in O(1), enabling persistent context for edge deployment. *(arXiv)*
- **[Self-improving LLMs via progressive experience evolution](https://arxiv.org/abs/2608.02139)** — A mechanism that turns transient interaction experience into persistent model capabilities, addressing fragmentation across test-time and self-improvement methods. *(arXiv)*
- **[Cooperative coevolution for memory-efficient agentic LLM post-training](https://arxiv.org/abs/2608.02391)** — An evolution-strategies approach that does full-parameter post-training of tool-using agents without backpropagation, matching gradient-based performance at lower memory cost. *(arXiv)*
- **[LEAP: critic-free code RL for GPU kernel generation](https://arxiv.org/abs/2608.01804)** — An adaptive environment-feedback pruning method built on GRPO that bypasses critic-network memory overhead for reinforcement-learning-driven GPU kernel generation. *(arXiv)*
