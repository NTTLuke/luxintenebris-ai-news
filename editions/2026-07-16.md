## Lead Open-weights milestone: Thinking Machines releases Inkling, a 975B MoE open-weights model with 1M token context

Thinking Machines released Inkling, a 975B total / 41B active parameter open-source MoE model with up to 1M token context and native multimodal reasoning over text, images, and audio. The model features ShortConv attention, shared expert sink MoE, and day-one production support via SGLang with CUDA graph prefill, MXFP8 KV cache, and DFlash speculative decoding. Open weights are available immediately.

Source: [LMSYS Org / Thinking Machines](https://x.com/lmsysorg/status/2077457150046269779)

## Research & Papers

- **[E3 framework estimates task complexity, cutting AI agent costs by 85%](https://arxiv.org/abs/2607.13034)** — The E3 framework estimates task complexity upfront and executes minimal viable paths, matching baselines on MSE-Bench while cutting cost by 85%, tokens by 91%, and inspected files by 92%. *(arXiv)*
- **[Audio-native speech recognition with frozen 26B DiffusionGemma language model](https://arxiv.org/abs/2607.13013)** — An audio-native interface paired with Whisper encoder and lightweight adapters achieves 6.6% WER on LibriSpeech test-clean, supporting multiple languages while training only 0.16% of backbone parameters. *(arXiv)*
- **[Resist and Update: CRC clamp makes LLMs incentive-compatible](https://arxiv.org/abs/2607.12985)** — A low-rank CRC clamp renders LLM outputs invariant to forbidden influences while remaining responsive to licensed evidence, achieving near-perfect resist-and-update performance on Bayesian witness benchmarks with strong cross-model transfer. *(arXiv)*
- **[SpectraReward repurposes MLLMs as zero-shot reward models for text-to-image generation](https://huggingface.co/papers/2607.11886)** — SpectraReward uses pretrained MLLMs as training-free zero-shot reward models for text-to-image RL by measuring prompt recoverability from generated images, consistently improving diffusion model performance. *(Hugging Face)*
- **[Function-aware fill-in-the-middle training for coding agent foundation models](https://huggingface.co/papers/2607.12463)** — Function-aware FIM mid-training on code corpora improves coding agents' handling of tool returns and action-observation loops, yielding gains on SWE-Bench while reducing capability erosion on other benchmarks. *(Hugging Face)*
