## Research & Papers

- **[Hourglass reasoning enforces rigorous induction-deduction separation, gains 14 points on ARC-AGI-2](https://arxiv.org/abs/2607.11696)** — Think Through a Bottleneck enforces strict isolation between induction and deduction stages in frozen LLMs, yielding up to 14-point gains on ARC-AGI-2 and nearly doubling Verilog synthesis accuracy on ChipBench. *(arXiv)*
- **[Weak-to-strong generalization via direct on-policy distillation boosts Qwen3-1.7B by 10 points on AIME](https://huggingface.co/papers/2607.05394)** — Direct-OPD transfers RL policy shifts from weaker to stronger models using implicit reward signals, boosting Qwen3-1.7B from 48.3% to 58.3% on AIME 2024 in 4 hours on 8 A100 GPUs. *(HuggingFace)*
- **[ABot-N1: A general visual language navigation foundation model with slow-fast architecture](https://huggingface.co/papers/2607.10383)** — ABot-N1 decouples cognition from control using a slow-fast architecture, achieving SOTA urban-scale navigation with POI arrival boosted from 35% to 77.3% and 95.4%/92.9% SR in complex indoor/outdoor scenes. *(HuggingFace)*
- **[ABot-AgentOS: A general robotic agent OS with lifelong multimodal memory and self-evolution](https://huggingface.co/papers/2607.10350)** — ABot-AgentOS provides a deliberative agent layer with Universal Multi-modal Graph Memory and self-evolution, achieving 88.7 on LoCoMo and 60.4 on OpenEQA EM-EQA with failure-driven improvement. *(HuggingFace)*
- **[4D human-scene reconstruction from low-overlap captures achieves SOTA with +5 dB PSNR gains](https://huggingface.co/papers/2607.09125)** — StudioRecon decouples background and humans using video diffusion densification and deformable Gaussians, achieving SOTA novel view synthesis with +1.5 to +5.0 dB PSNR gains over prior methods. *(HuggingFace)*

## Open Source & Models

- **[GLM-5.2: Zhipu AI releases new open-weights model with IndexShare DSA architecture](https://x.com/togethercompute/status/2077097332169191830)** — Zhipu AI released GLM-5.2, a new open-weights model featuring IndexShare in its DSA layers and a stronger Multi-Token Prediction head reusing IndexShare and KVShare techniques. Available on Hugging Face. *(@togethercompute)*
- **[Bonsai 27B: First 27B-class multimodal model to run on a phone, Apache 2.0 license](https://prismml.com/news/bonsai-27b)** — PrismML released Bonsai 27B, based on Qwen3.6, using ternary {-1,0,+1} weights with FP16 scaling (1.71 bits/weight, 5.9 GB). Retains roughly 95% of full-precision performance on reasoning, tool-calling, vision, and agentic tasks with 262K context. A 1-bit variant at 3.9 GB fits iPhones. *(PrismML)*
- **[Serving GLM-5.2 NVFP4 with SGLang: 500+ TPS on 8x Blackwell B300](https://www.lmsys.org/blog/2026-07-13-glm52-optimization)** — LMSYS published optimizations for serving GLM-5.2 on Blackwell hardware, achieving 500+ tokens/s per user at batch size 1. Key wins include 18-34% better single-user interactivity and a new TopK-V2 kernel 2.33x faster at 80K context. *(LMSYS)*
- **[NVIDIA Nemotron 3 Ultra: Ralph loops for agentic performance with LangChain Deep Agents](https://developer.nvidia.com/blog/create-a-langchain-deep-agents-harness-profile-for-nvidia-nemotron-3-ultra-to-improve-performance/)** — NVIDIA published a technical blog on Ralph loops — iterative agentic patterns using filesystem as persistent memory — with LangChain Deep Agents Harness for Nemotron 3 Ultra. Tuning the harness rather than the model improves agent benchmarks without fine-tuning. *(NVIDIA Developer Blog)*
