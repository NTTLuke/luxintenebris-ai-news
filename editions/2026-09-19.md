## Research & Papers

- **[NVIDIA's SoL-Pi harness cuts agent token traffic by roughly half](https://x.com/omarsar0/status/2101074795643494546)** — NVlabs open-sourced SoL-Pi, an evolutionary approach that tunes agent harness mechanisms like action fusion and online context compacting, nearly halving token usage while matching stronger baselines. *(@omarsar0)*
- **[Empirical study isolates which harness choices matter for coding agents](https://x.com/_akhaliq/status/2101020560964866103)** — Using a lightweight harness with a fixed execution loop, the study separates the effect of individual scaffolding decisions on long-horizon software-engineering performance and cost. *(@_akhaliq)*
- **[EvoSkill v2 lets agents self-improve without retraining weights](https://x.com/omarsar0/status/2100989618845823364)** — A coach agent writes persistent skill lessons from failed runs that a worker agent loads on similar tasks, lifting hard spreadsheet-task success from 3/120 to 21/120 with proper separation and review. *(@omarsar0)*
