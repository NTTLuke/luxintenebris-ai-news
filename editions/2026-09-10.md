## Research & Papers

- **[Show-Harness: just a VLM agent can play robots](https://arxiv.org/abs/2609.10522)** — An embodied harness lets a vision-language model control real robots through a compact intent-to-action interface, without a dedicated policy network. *(arXiv)*
- **[ConvMem: convolutional memory for long-context reasoning](https://arxiv.org/abs/2609.10441)** — A convolutional memory module replaces fixed-size sequential memory, extending effective context and improving long-context reasoning. *(arXiv)*
- **[TRACE: training reasoning agents for causal exploration](https://arxiv.org/abs/2609.10315)** — Diagnostic reasoning agents learn to explore causal explanations using synthesized verifiable rewards, beating RLVR baselines on anomaly diagnosis. *(arXiv)*
- **[Sample-adaptive strategy routing for vision token pruning](https://arxiv.org/abs/2609.10346)** — Per-sample routing among token-pruning strategies cuts multimodal LLM inference cost while preserving accuracy. *(arXiv)*
- **[On-policy distillation for vision-language model adaptation](https://arxiv.org/abs/2609.10321)** — Per-sample targets drawn from the student's own rollouts improve VLM adaptation on noisy, low-quality multimodal data. *(arXiv)*
- **[Google paper: procedural graph for long-horizon agents](https://x.com/omarsar0/status/2097755424007373270)** — Agents query next-step procedures that self-rewrite via an LLM refiner, matching or beating hand-designed graphs for self-evolving agents. *(omarsar0)*
