## Research & Papers

- **[Repeated sampling beats self-refine and reflexion at equal token cost](https://arxiv.org/abs/2607.28576)** — A controlled study from 1.5B to 7B models shows reflection methods that generate extra text are beaten by simple repeated sampling at equal token budgets, isolating the accuracy gain of reflection to generating more tokens. *(arXiv)*
- **[Echoverse generates deep, evolving environments to train computer-use agents](https://arxiv.org/abs/2607.28074)** — The pipeline generates reset-able synthetic environments for computer-use agent training, targeting stateful login-gated applications and scaling beyond prior bulk pipelines. *(arXiv)*
- **[Memory Decoder at Scale: a pretrained, parametric long-term memory for LMs](https://arxiv.org/abs/2607.27919)** — Scales a parametric long-term memory module to much larger capacities, decoupling memory from reasoning parameters for independently scalable long-term memory. *(HuggingFace)*
- **[WIDE boosts adaptive LLM inference via token-level dynamic width pruning](https://arxiv.org/abs/2607.28418)** — Token-level dynamic width pruning allocates compute per token to reduce accuracy loss under aggressive sparsity versus static structured pruning. *(arXiv)*
- **[ReToken adds a retrieval token to improve vision-language models on visual retrieval](https://arxiv.org/abs/2607.28627)** — A single learnable embedding as an explicit retrieval token lets VLMs handle long visual context with many distractors while staying within GPU memory. *(arXiv)*
