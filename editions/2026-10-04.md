## Top stories

### Cloudflare releases Clef and Clef-Flash, open-weight 'decision models' under Apache 2.0

Cloudflare shipped Clef (27B, post-trained from Qwen3.8-27B) and Clef-Flash (9B, from Qwen3.5-9B): multimodal decision models that return calibrated probabilities over a fixed typed schema instead of free-form text, with 64K context, Ollama support and hosted inference on Workers AI. Cloudflare claims its threat-intel team runs end-to-end website classification in ~2.2s with Clef versus ~4.7s with its fastest general-purpose open LLM, and it also announced an RL fine-tuning platform for custom decision categories.

Source: [Cloudflare](https://x.com/GlobalFeedAI/status/2106477677293023465)

### CMU trains a 4B proposer that edits agent harness code and beats its 35B teacher

A CMU paper trains a proposer model with RL to read a task, the current harness and an execution report, then propose code edits to the harness while the solver model stays frozen. The trained 4B proposer beats its 35B teacher on single-step revisions in Reasoning Gym, including unseen task families, and a HotpotQA-trained version generalizes to MuSiQue and 2WikiMultihopQA.

Source: [omarsar0 (X)](https://x.com/omarsar0/status/2106529236068819394)

### AutoCompact: agents trained to compact their own context gain +9.2 points on SWE-bench Verified

AutoCompact trains agents via SFT on judge-corrected trajectories plus RL with task-success rewards to decide when to compact context, what working state to preserve, and how to resume — delivering +9.2 points on SWE-bench Verified and +5.0 on SWE-PolyBench Verified, with gains persisting even in very large context windows.

Source: [omarsar0 (X)](https://x.com/omarsar0/status/2106416745686995025)

### Simon Willison: AI systems need hard, default-on budget caps

After repeated stories of agents racking up surprise bills in retry loops, Simon Willison argues that AI agents and LLM systems should ship with strictly enforced budget caps by default across token usage, cloud spend and API calls — with replies citing real cases, including Netlify moving to credit-based pricing.

Source: [simonw (X)](https://x.com/i/status/2106528704902164855)

## Research & Papers

- **[GPT-6 Astra robot agents hit 14% higher task success with 65% fewer tokens](https://arxiv.org/abs/2610.01939)** — PyRUA-Lean is an interactive code-execution framework for VLM robot agents that composes primitives into Python cells with conditional checks and selective observation. Across 700 simulated episodes it reports 14% higher task success with 65% fewer tokens than repeated full-observation invocations. *(arXiv)*
- **[LoopCD decodes looped transformers better for (almost) free](https://arxiv.org/abs/2610.02185)** — A training-free contrastive decoding method for looped transformers contrasts the final recurrent pass against an earlier pass in logit space. Recurrence provides aligned weak-and-strong prediction pairs for free, improving next-token selection without auxiliary models or extra training. *(arXiv)*
- **[Keyword harnesses fail open: a cheap diagnostic ladder for tool-use claims](https://arxiv.org/abs/2610.02142)** — Documents false positives in keyword-matching tool-use benchmarks: a 661.6M and a 1,109M Spanish security LLM score nearly identically on lenient metrics (0.660 vs 0.650), while verbatim-reproduction checks separate them completely. The authors propose a strict, cheap ladder for verifying tool-use claims. *(arXiv)*
- **[ROWBench asks whether video models render what the program specifies](https://huggingface.co/papers/2610.02205)** — A 170-episode, 600-proxy-video benchmark evaluates whether programmable world models visually render fine-grained, program-specified world events, logging entity states and timestamps for fidelity checks that existing visual-quality benchmarks miss. *(Hugging Face)*
- **[AutoGUIWorld uses image generators as visual world models for GUI agents](https://arxiv.org/abs/2610.01215)** — A data-generation framework that uses image generators' visual priors as a visual world model for GUI agents, synthesizing diverse interaction trajectories without deploying and configuring real software environments. *(arXiv)*
