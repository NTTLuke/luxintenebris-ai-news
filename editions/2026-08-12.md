## Research & Papers

- **[Why does CLAUDE.md keep growing? 'Catastrophic remembering' in agentic coding](https://arxiv.org/abs/2608.11095)** — Across 247,694 instruction lifetimes in 1,867 repos, agentic prompts grow +226% over their lifetime, with older instructions increasingly unlikely to be deleted. Comments that encode latent reasoning remove 99.3% of excess instructions and improve real-world instruction-following by up to 23.1%. *(arXiv)*
- **[DSAgentBench: agents still struggle to automate end-to-end data science](https://arxiv.org/abs/2608.10366)** — The first benchmark evaluating agents across full data-science workflows in real computer environments finds the strongest agent (Claude-4.6-Sonnet) reaches only 56.70% task success, while all open-source agents stay below 1%. *(arXiv)*
- **[V-FiLLM: a verified benchmark for financial LLM reasoning](https://arxiv.org/abs/2608.11047)** — Generates financial reasoning benchmarks from executable computation trees grounded in real tables, with answers correct by construction. Accuracy falls up to 51% with reasoning depth, and lightweight LoRA fine-tuning lifts it from 81.1% to 85.6%. *(arXiv)*
- **[Latent Critic detects hallucinations in a single forward pass](https://arxiv.org/abs/2608.10430)** — A lightweight LoRA running alongside a frozen LLM restructures the residual stream to localize hallucinations in one pass, reaching 0.966 AUROC and >80% localization accuracy for tool-calling, acting as a negligible-latency guardrail in ReAct loops. *(arXiv)*
- **[VibeLifeBench: life agents fall short in a living world](https://arxiv.org/abs/2608.10875)** — A 200-task benchmark across ten everyday-life domains, each a scripted multi-week timeline with silent changes requiring proactive re-inspection, finds all seven frontier models score low — current agents are far from real-life assistance. *(arXiv)*
