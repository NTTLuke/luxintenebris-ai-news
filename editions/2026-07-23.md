## Research & Papers

- **[PoTRE achieves 49.92% SOTA on Humanity's Last Exam with heterogeneous reasoning agents](https://arxiv.org/abs/2607.20268)** — Decouples inference into four heterogeneous reasoning agents with Task-Adaptive Aggregation, surpassing the previous best official HLE score using similar or fewer tokens. Accepted at TMLR 2026. *(arXiv)*
- **[SLAI T-Rex post-trains DeepSeek-V4 on Ascend SuperPOD, outperforms GPT-5.4-Mini on OR tasks](https://arxiv.org/abs/2607.20145)** — Achieves 34.22% MFU on Ascend NPU SuperPOD for trillion-parameter MoE post-training; the OR-specialized model reaches 71.81% zero-shot Pass@1, beating GPT-5.4-Mini by 3.98 points. *(arXiv)*
- **[PRO-LONG achieves 76.1% pass@1 on ARC-AGI-3 with programmatic memory for LLM agents](https://arxiv.org/abs/2607.20064)** — Uses a minimal context management framework with programmatic memory, reaching 97.4% best@2 with Fable 5 while using 4.2-5.8x fewer tokens than SOTA specialized harnesses. *(arXiv)*
- **[ATSplat renders novel views at 1136 FPS with 5.7x fewer Gaussians via adaptive token expansion](https://arxiv.org/abs/2607.20417)** — Restores adaptive primitive allocation in feed-forward 3DGS using sparse 3D anchor tokens, achieving SOTA rendering quality on RealEstate10K and DL3DV with only 311K Gaussians. *(arXiv)*
- **[SLPO brings outcome-reward RL to autoregressive latent reasoners via surrogate policy optimization](https://arxiv.org/abs/2607.19691)** — Uses an empirical surrogate policy density for trajectory credit assignment and a correctness-supervised stopping head, improving Pass@k under parallel sampling. *(arXiv)*
