Hidden reasoning must leak, but need not be readable: formal limits for chain-of-thought monitoring

Hidden reasoning must leak, but need not be readable: formal limits for chain-of-thought monitoring

Asks whether reasoning models can perform hidden computation without revealing it in thinking traces. Shows the answer depends on task difficulty and model size: simple computations can be hidden from CoT monitors, with formal limits on monitorability.

arXiv · 2026-09-29

EasyPPO: stabilizing the critic is key to reliable LLM reinforcement learning

Identifies the PPO critic as a major source of instability in RL for LLMs, pinpointing two critic failure modes. Stabilizing the critic is presented as the key to stable LLM RL training.

HuggingFace · 2026-09-29

S^3: spectral null-space swap makes reasoning models efficient

Finds that chain-of-thought capacity lives mainly in a thinking model's weight component within a null space defined relative to an Instruct model. A spectral null-space swap transfers reasoning ability while cutting excessive reasoning-token cost.

arXiv · 2026-09-29

LeapQuant: accurate recurrent-state quantization for linear-attention LLMs

Targets hybrid LLMs using linear attention (Gated DeltaNet, Kimi Delta Attention) and fixes the accuracy collapse that occurs when their fixed-size recurrent states are quantized to low precision, keeping long-context quality while cutting serving memory.

SelfSearch: reward-free search for self-improving agents

Coding agents inspect and modify their own instructions, tools and execution procedures without any downstream reward signal, removing the repeated evaluation cost that existing self-improving agent loops incur.
